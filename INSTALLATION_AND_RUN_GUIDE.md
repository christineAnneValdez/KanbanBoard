# Task Kanban Setup Guide

This guide is for a new user setting up and running the project locally.

## Project Structure

This repository has two applications:

- `laravel_backend` (Laravel API + Backpack admin)
- `nuxt_frontend` (Nuxt frontend)

## 1. Prerequisites

Install these tools first:

- PHP `8.2+`
- Composer `2+`
- Node.js `20+`
- npm
- MySQL `8+` (or compatible)

## 2. Installation

## 2.1 Clone and open project

```powershell
git clone <your-repo-url>
cd task-kanban
```

## 2.2 Backend install (`laravel_backend`)

```powershell
cd laravel_backend
composer install
npm install
Copy-Item .env.example .env -ErrorAction SilentlyContinue
php artisan key:generate
```

## 2.3 Frontend install (`nuxt_frontend`)

Open a second terminal:

```powershell
cd nuxt_frontend
npm install
```

## 3. Environment Setup (MySQL)

Edit `laravel_backend/.env` and use these values:

```env
APP_NAME=Laravel
APP_ENV=local
APP_KEY=
APP_DEBUG=true
APP_URL=http://127.0.0.1:8000

DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=task_kanban
DB_USERNAME=root
DB_PASSWORD=your_mysql_password

SESSION_DRIVER=database
QUEUE_CONNECTION=database
CACHE_STORE=database

SANCTUM_STATEFUL_DOMAINS=localhost:3000,127.0.0.1:8000,localhost,127.0.0.1,::1
```

Notes:

- `APP_KEY` is generated by `php artisan key:generate`.
- Backend CORS is configured for `http://localhost:3000`.

Optional frontend env (`nuxt_frontend/.env`):

```env
VITE_API_BASE_URL=http://127.0.0.1:8000/api
```

## 4. Create Database and Run Migrations

Create database in MySQL:

```sql
CREATE DATABASE task_kanban CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

Then run backend migrations and seed:

```powershell
cd laravel_backend
php artisan migrate
php artisan db:seed
```

Default seeded user:

- Email: `test@example.com`
- Password: `password`

## 5. How to Run the Project

Run backend:

```powershell
cd laravel_backend
php artisan serve
```

Backend URL:

- `http://127.0.0.1:8000`

Run frontend (second terminal):

```powershell
cd nuxt_frontend
npm run dev
```

Frontend URL:

- `http://localhost:3000`

## 6. How to Add/Appoint an Admin

This project uses Spatie roles and checks for role `admin` on Backpack routes.

Open Tinker:

```powershell
cd laravel_backend
php artisan tinker
```

Run:

```php
use App\Models\User;
use Spatie\Permission\Models\Role;

$role = Role::firstOrCreate(['name' => 'admin']);
$user = User::where('email', 'test@example.com')->first(); // change email if needed
$user->assignRole($role);
```

Verify:

```php
$user->hasRole('admin');
```

If it returns `true`, that user is now an admin.
